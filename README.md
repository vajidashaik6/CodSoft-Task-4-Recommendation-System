# 🎬 MovieMind AI – Movie Recommendation System

MovieMind AI is a web-based movie recommendation system that suggests similar movies based on the user's selected movie.

## 🚀 Features

- 🎬 Movie recommendation
- 🤖 AI-based similarity analysis
- 🔍 Movie search
- 🌐 Flask web interface
- 📊 TF-IDF based text processing
- 🔗 Cosine Similarity for recommendations
- 💻 Simple and responsive UI

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- Scikit-learn
- HTML
- CSS
- JavaScript
